# 定义

**连接器系统** 把外部第三方服务接入 [[豆包客户端]]，由服务端实现；前端硬编码路由前缀 `/alice/office/manage/connector/` 与 `/connector/`。

# 关键属性（端点清单）

| 端点 | 语义推断 |
|---|---|
| `manage/connector/create_personal` | 创建个人连接器 |
| `manage/connector/connect` | 建立连接 |
| `manage/connector/disconnect` | 断开连接 |
| `manage/connector/batch_update_status` | 批量更新连接状态 |
| `manage/connector/oauth/authorize_url` | 获取 OAuth 授权 URL |
| `manage/connector/oauth/finish` | 完成 OAuth 流程（回调换 token） |
| `manage/connector/oauth/status` | 查询 OAuth 状态 |
| `connector/install_feishu` | 安装飞书连接器 |
| `connector/list_by_user` | 按用户列出连接器 |
| `connector/set_conversation_enabled` | 会话级启用开关 |

# 关系

- 宿主：[[豆包客户端]]；与 [[技能系统]] 共同构成技能形态（[[技能即安装包与 OAuth 连接器]]）。
- 与 [[设备下发通道]] 同属**需授权的对外通道**，权限模型可比对，见 [[远程控制通道与权限风险]]。
- 与 [[MCP]] 的 server 接入概念同构（但走私有协议）。

# 开放问题

- OAuth token 的存放位置（本地/云端）与可见性未知 —— 涉及凭据安全。
- `set_conversation_enabled` 表明连接器可在**会话粒度**生效，可能构成权限旁路点。

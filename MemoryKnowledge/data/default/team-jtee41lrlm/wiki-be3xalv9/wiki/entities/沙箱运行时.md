# 定义

`User Data\sandbox_runtime` 是 [[豆包 PC 客户端]] 随包分发的**可执行沙箱**，为 [[编程模式（coding）]] 与 [[子 agent]] 提供能真正跑起代码的环境。

# 关键属性

| 属性 | 值 |
|---|---|
| 路径 | `User Data\sandbox_runtime` |
| 体积 | 519 MB |
| 内置运行时 | Node + Python |
| 包管理缓存 | npm 缓存 + pip 缓存 |

体积主要来自运行时与包缓存——这也是「长任务可离线执行」的前提。

# 关系

- 被 [[编程模式（coding）]] 与 [[子 agent]] 使用。
- 是 [[沙箱内子 agent 长任务模式]] 结论「必须有 Node + Python 沙箱」的直接来源。
- 与 [[任务模式 runtime-bundle]] 并列：一个提供可写代码的沙箱，一个提供后台长任务运行时。

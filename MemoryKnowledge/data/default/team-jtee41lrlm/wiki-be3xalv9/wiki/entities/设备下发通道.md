# 定义

**设备下发通道** 是 [[豆包客户端]] 的跨设备控制面，服务端实现，路由前缀 `/alice/dispatch/`。它能把指令下发到用户的其他设备并回收执行回执，同时管理设备授权与 RTC 会话 —— 本质上是一条**远程控制通道**。

# 关键属性（端点清单）

| 端点 | 语义推断 |
|---|---|
| `all_devices` / `list_devices` | 枚举设备 |
| `get_device_info` | 设备详情 |
| `send_command` | 下发指令 |
| `send_command_result` | 回执/结果回传 |
| `authorize/device` | 设备授权 |
| `authorize/device/cancel` | 取消授权 |
| `report_device` | 设备上报 |
| `get_device_connections` | 设备连接关系 |
| `rtc/session_meta` | RTC 会话元信息 |
| `setting/user` | 用户设置 |

# 关系

- 宿主：[[豆包客户端]]。
- 与 [[连接器系统]] 并列：两者都需授权，但本通道的**指令执行语义**风险更高，见 [[远程控制通道与权限风险]]。
- 权限控制可能依赖 [[服务端下发的能力开关]]（未在本记录中得到直接证据）。

# 风险提示

具备「指令下发 + 回执 + 设备授权 + RTC 会话」四要素，等价于一个远程控制面，应作为安全评审重点：谁能下发、下发范围、设备授权撤销时效、回执是否可被伪造。

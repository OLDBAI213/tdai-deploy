# 定义

编程模式（coding）是 [[豆包 PC 客户端]] 中最具「自主执行」色彩的模式：落点 `User Data\coding`，能够启动 [[子 agent]]，在沙箱里写代码，并**直接改动本机文件系统上的文件**。

# 关键属性

- 路径：`User Data\coding`
- 执行主体：[[子 agent]]（会话 ID 形如 `s_xxxx`）
- 落盘工具：`Write`（`firstToolName=Write` 是快照中的高频首工具）
- 依赖：[[沙箱运行时]]（Node + Python + npm/pip 缓存）
- 痕迹：每次执行在 [[执行快照目录]] 留下结构化元数据，且**不做清理**

# 关系

- 与 [[沙箱内子 agent 长任务模式]] 互为条件：编程模式提供执行主体，沙箱提供可执行环境。
- 是 [[本地任意目录读写权限模型]] 的直接证据来源，与 [[本地执行痕迹]] 互为印证。

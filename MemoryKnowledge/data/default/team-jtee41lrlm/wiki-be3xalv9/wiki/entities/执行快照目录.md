# 定义

`User Data\coding\snapshot\` 是 [[编程模式（coding）]] 的执行快照落点：每完成一次 [[子 agent]] 执行，就在这里留下一条结构化记录。

# 关键属性

- 路径：`User Data\coding\snapshot\`
- 记录粒度：一次子 agent 执行一条
- 字段：`agentType` / `agentId` / `sandboxId` / `firstToolName` / `addedLines` / `changeType`
- 留存策略：**不清理**（无轮转、无过期）

逆向时该目录下有 5 条记录，全部集中在 2026-09-26 14:06–14:14。

# 关系

- 是 [[子 agent]] 执行行为的记录载体，构成 [[本地执行痕迹]]。
- 与 [[本地任意目录读写权限模型]] 互为证据：快照证明了写入范围，权限模型解释了其后果。

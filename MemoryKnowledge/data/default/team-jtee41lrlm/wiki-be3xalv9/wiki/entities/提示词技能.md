# 定义

**提示词技能** 是 [[豆包客户端]] 中把「一段提示词」注册为可调用能力的子系统，服务端实现，路由前缀 `/samantha/plugin/prompt_skill/`。

# 关键属性（端点清单）

| 端点 | 语义推断 |
|---|---|
| `list_discover_skills` | 列出可发现/推荐的提示词技能 |
| `PluginAddPromptSkill` | 注册提示词技能 |
| `PluginDeletePromptSkill` | 删除提示词技能 |

# 关系

- 宿主：[[豆包客户端]]。
- 概念化表达：[[提示词即技能]] —— 提示词本身成为一等能力单元。
- 与 [[技能系统]]（包 + 连接器型技能）并列，说明豆包的「skill」是一族异构能力的统称。

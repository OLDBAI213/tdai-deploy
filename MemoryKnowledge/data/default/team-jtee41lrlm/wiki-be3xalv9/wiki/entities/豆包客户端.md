# 定义

**豆包客户端（Doubao）** 是本次逆向的目标桌面应用。其架构呈现明显的双层结构：客户端内携带可执行工具的**本地执行层**，而技能市场、连接器、设备下发等**编排能力全部在云端**。

# 关键属性

| 属性 | 值 |
|---|---|
| 安装根目录 | `%LOCALAPPDATA%\Doubao\Application\app\` |
| 渲染层产物 | [[local_webcontents 前端产物]]（2113 个 JS/JSON，494 MB） |
| 运行形态 | 渲染层 web app（Electron 特征全 0，见 [[运行时类型判定]]） |
| 本地工具包 | `task-mode-resource\python-packages`，见 [[本地执行层（python-packages）]] |

# 定义

**技能系统** 是 [[豆包客户端]] 的技能管理服务，全部逻辑在服务端；前端 `entry-moa/main.js` 仅硬编码其 API 路由（前缀 `/alice/office/skills/`）。它提供技能的增加、删除、查询、企业版视图、授权与安装包下载。

# 关键属性（端点清单）

| 端点 | 语义推断 |
|---|---|
| `add` | 新增技能 |
| `delete_by_identity` | 按身份删除 |
| `get_detail` | 技能详情 |
| `get_enterprise_detail` | 企业版技能详情 |
| `get_download_link` | 获取下载链接（技能包） |
| `get_exposed` | 已暴露/已启用技能列表 |
| `list_my` | 我的技能 |
| `list_enterprise` | 企业技能列表 |
| `list_user_and_featured` | 用户技能 + 精选 |
| `batch_get_package_urls` | 批量取技能包 URL |
| `batch_save_briefs` | 批量保存简述 |
| `authorization/submit_outcome` | 授权结果回传 |
| `check_enterprise_admin_permission` | 企业管理员权限校验 |

# 关系

- 宿主：[[豆包客户端]]；调用方前端：[[local_webcontents 前端产物]]。
- 与 [[连接器系统]] 组合构成豆包的「技能 = 安装包 + OAuth 连接器」形态，见 [[技能即安装包与 OAuth 连接器]]。
- 企业版维度（`enterprise`、`admin_permission`）说明存在**组织级权限模型**，是后续需补证的方向。
